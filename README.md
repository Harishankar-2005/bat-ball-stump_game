# Bat Ball Stump Game

A Cricket-themed Rock Paper Scissors game built with HTML, CSS, and JavaScript.

## How to Play

- Choose **Bat**, **Ball**, or **Stump**
- The computer randomly picks one too
- **Bat beats Ball** | **Ball beats Stump** | **Stump beats Bat**
- Your score is saved even after closing the browser!

## Features

- Cricket themed Rock Paper Scissors gameplay
- Score tracking (Win / Lost / Tie)
- Persistent score using localStorage
- Reset button with old score memory
- Stadium background UI

## Project Structure

```
index.html      # Game markup and logic
style.css       # Styling and layout
bat.png         # Bat image
ball.png        # Ball image
stump.jpg       # Stump image
stadium.png     # Background image
```

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (localStorage for score persistence)
